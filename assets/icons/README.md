# Meter icons

Gauge and Database, 20 regular, from Microsoft's Fluent System Icons.

Source revision: `60d561a815310bd52914fa0bccee14836428e23b`.

- https://github.com/microsoft/fluentui-system-icons/blob/60d561a815310bd52914fa0bccee14836428e23b/assets/Gauge/PDF/ic_fluent_gauge_20_regular.pdf
- https://github.com/microsoft/fluentui-system-icons/blob/60d561a815310bd52914fa0bccee14836428e23b/assets/Database/PDF/ic_fluent_database_20_regular.pdf

The original vectors are retained under `source/`, and `LICENSE` contains the
upstream MIT notice. PNGs are rendered from these vectors, with transparent
backgrounds and a neutral grey tint. Regenerate on macOS with:

```sh
swift scripts/render-icons.swift assets/icons
```
